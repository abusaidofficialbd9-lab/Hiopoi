# 🤖 Ay Chat Bot Maker

একটি মাস্টার বট, যার মাধ্যমে আপনার ইউজাররা **সোর্স কোড ছাড়াই** নিজের Gemini AI Chat Bot বানাতে পারে।
ইউজার শুধু ৩টি জিনিস দেয়: **Bot Token + Gemini API Key + Admin ID** → **Create** → বট চালু।

## ইউজার যা পাবে
- `/start` → হোম মেনু, চ্যানেল/গ্রুপ নোটিশ, Token ও Gemini Key বানানোর গাইড + লিংক
- চ্যানেল ও গ্রুপে জয়েন না থাকলে বট বানাতে পারবে না (Force Join, ওনার বন্ধ করতে পারবেন)
- ধাপে ধাপে: Token → Gemini Key → Admin ID (বা "আমার ID" বাটন) → সারাংশ → **✅ Create**
- Token/Key পাঠালেই মেসেজ চ্যাট থেকে মুছে যায়; Key আগেই টেস্ট হয়
- `/mybots` → বটের Key বদলানো, এডমিন যোগ/সরানো, চালু/বন্ধ, ডিলিট
- নিজের বটে `/admin` (শুধু এডমিন): এডমিন, একাধিক Key (অটো ফেইলওভার), মডেল, ইনবক্স/গ্রুপ ON-OFF,
  /off /on (চ্যাট ভিত্তিক), কাস্টম নির্দেশনা (persona), Welcome মেসেজ, ব্রডকাস্ট, স্ট্যাটাস

## আপনার (Owner) প্যানেল — মাস্টার বটে `/panel`
সব বটের তালিকা (সাসপেন্ড/ডিলিট), ইউজার ব্যান/আনব্যান, প্রতি ইউজার বট লিমিট, ডিফল্ট মডেল,
Force Join ON/OFF, Maintenance মোড, নোটিশ, সব ইউজারকে ব্রডকাস্ট, এখনই সেভ।

## আলাদা থাকার নিশ্চয়তা
প্রতিটি বটের আলাদা: Token, Key, এডমিন, সেটিংস, হিস্ট্রি, ইউজার লিস্ট, আলাদা webhook, আলাদা ডাটা-ফাইল।
একটির ডাটা অন্যটির রানটাইমে মেশার কোনো পথ নেই। Token ও Key `SECRET_KEY` দিয়ে এনক্রিপ্ট হয়ে সেভ হয়।

## সেটআপ
1. **নতুন একটি Telegram গ্রুপ** (Topics চালু) বানান — শুধু এই সিস্টেমের ডাটার জন্য। (পুরোনো Ay Chat Bot-এর গ্রুপ ব্যবহার করবেন না।)
2. @BotFather থেকে **মাস্টার বট** বানান; মাস্টার বটকে ওই গ্রুপে এডমিন (মেসেজ পাঠানো, মুছা, পিন) করুন।
3. মাস্টার বটকে আপনার **চ্যানেল ও গ্রুপে এডমিন** বানান (নইলে Force Join চেক করা যায় না)।
4. GitHub-এ এই ফোল্ডার আপলোড → Render → **New Web Service**
   - Build: `pip install -r requirements.txt` • Start: `python main.py`
5. Render → Environment:

| Variable | কী দেবেন |
|---|---|
| `BOT_TOKEN` | মাস্টার বটের Token |
| `OWNER_ID` | আপনার Telegram ID |
| `LOG_GROUP_ID` | ডাটা গ্রুপের ID (যেমন -100…) |
| `LOG_TOPIC_ID` | টপিক ID (টপিক না থাকলে `0`) |
| `SECRET_KEY` | যেকোনো লম্বা গোপন লেখা — **একবার দিয়ে আর কখনো বদলাবেন না** (বদলালে সেভ করা Token/Key পড়া যাবে না) |
| `GEMINI_MODEL` | ঐচ্ছিক, ডিফল্ট `gemini-3.5-flash-lite` |
| `MAX_BOTS_PER_USER` | ঐচ্ছিক, ডিফল্ট 2 |
| `REGISTRY_MESSAGE_ID` | প্রথম চালুর পর বট আপনাকে ইনবক্সে যে ID দেবে সেটি বসান |

ব্র্যান্ডের লিংক/নাম বদলাতে চাইলে ঐচ্ছিক ভেরিয়েবল: `PLATFORM_NAME, OWNER_NAME, OWNER_CONTACT, OWNER_URL, CHANNEL_URL, GROUP_URL, JOIN_CHANNEL, JOIN_GROUP`।

6. Deploy হলে মাস্টার বটে `/start` দিন। Render Free হলে বাইরে থেকে `/health` লিংকে UptimeRobot দিয়ে পিং করান।

## ইউজারদের জন্য জরুরি টিপ
গ্রুপে সব মেসেজের উত্তর পেতে বটের **Group Privacy বন্ধ** করতে হয় (BotFather → /mybots → Bot Settings → Group Privacy → Turn off)। বট বানানো শেষে মাস্টার বট নিজেই এটি জানিয়ে দেয়।

## সীমাবদ্ধতা (জেনে রাখুন)
- ডাটা Telegram গ্রুপে থাকে। সেভ ~৩.৫ সেকেন্ড অন্তর একটা একটা করে হয়, তাই অনেক বট একসাথে সক্রিয় থাকলে (প্রায় ১০০+) হিস্ট্রি সেভে কয়েক মিনিট দেরি হতে পারে। রিস্টার্টে শেষ কয়েক মিনিটের হিস্ট্রি হারানোর ঝুঁকি আছে (সেটিংস নয়)। বড় হলে MongoDB/Postgres-এ সরানো ভালো।
- প্রতিটি ইউজারের নিজের Gemini Key, তাই লিমিট/খরচ তার নিজের। এক ইউজার প্রতি বটে মিনিটে ১৫টির বেশি মেসেজ করলে বাকিগুলো উপেক্ষা হয়।
- আপনি (Owner) চাইলে কোনো বট সাসপেন্ড/ডিলিট করতে পারেন; চ্যাট কনটেন্ট আপনার গ্রুপে লগ হয় না (শুধু বট তৈরি/ডিলিট ইভেন্ট)।
